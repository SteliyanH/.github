# Getting help

**Questions** ("how do I…") go to
[kadr's Discussions](https://github.com/SteliyanH/kadr/discussions), for every
kadr package. Answers stay findable there for the next person.

**Documentation** is hosted on the Swift Package Index:

- [kadr](https://swiftpackageindex.com/SteliyanH/kadr/documentation/kadr): start
  with Getting Started and the Cookbook.
- [kadr-ui](https://swiftpackageindex.com/SteliyanH/kadr-ui/documentation),
  [kadr-captions](https://swiftpackageindex.com/SteliyanH/kadr-captions/documentation),
  [kadr-photos](https://swiftpackageindex.com/SteliyanH/kadr-photos/documentation),
  [kadr-audio](https://swiftpackageindex.com/SteliyanH/kadr-audio/documentation),
  [kadr-persistence](https://swiftpackageindex.com/SteliyanH/kadr-persistence/documentation).

**Bugs** go in an issue on the package's own repository. The bug form asks for
the smallest `Video { … }` that shows the problem. That is usually all it takes
to reproduce one.

**Security problems** should not go in a public issue. See
[SECURITY.md](SECURITY.md).
